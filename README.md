# 🧠 Data Analysis Agent
An intelligent, agentic data analysis system powered by AI that autonomously explores, visualizes, and surfaces insights from your datasets. 
Built with Streamlit, featuring a chat interface, SQL console, and automatic dashboard generation.

## ✨ Key Features
- **🤖 Agentic Analysis** - AI autonomously plans and executes multi-step analysis workflows
- **📊 Auto Dashboards** - Intelligent chart selection based on data types and distributions
- **🗄️ SQL Powered** - Data stored in MySQL/SQLite with natural language to SQL translation
- **💬 Chat Interface** - Ask questions about your data and get answers with visualizations
- **🔍 Data Explorer** - Interactive exploration of your dataset with statistical summaries
- **📈 Advanced Visualization** - Powered by Plotly and Matplotlib for rich, interactive charts

# 💻 Usage
1. Upload Data
Launch the app and upload a CSV file from the home screen
The system automatically profiles your data and initializes the AI agent

2. Explore the Dashboard
View automatically generated visualizations
Get statistical summaries and insights
The agent intelligently selects chart types based on your data

3. Chat with Your Data
Use natural language to ask questions about your dataset
Get answers with relevant visualizations
The AI understands context and provides insights

4. Use SQL Console
Write SQL queries directly (works with stored data)
Or use natural language that gets converted to SQL
Explore data with full SQL flexibility

5. Data Explorer
Interactive filtering and sorting
Statistical summaries for each column
Data type analysis and distribution information
